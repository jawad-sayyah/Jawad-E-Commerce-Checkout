# Jawad E-Commerce Checkout Page

A simple and interactive E-Commerce Checkout Page built using **HTML, CSS, and Vanilla JavaScript**.

The project simulates the checkout process of an online store, allowing customers to review their orders, enter their information, select delivery and payment methods, apply promo codes, and complete their purchases.

## Technologies Used

- **HTML5** – Page structure and form elements.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript (Vanilla JS)** – Form validation, order calculations, and interactive functionality.
- **Local Storage** – Saving order history in the browser.

## Features

### 1. Customer Information
- Enter customer name, email, phone number, and delivery address.
- Validate required information before placing an order.
- Option to use a different billing address.

### 2. Order Summary
- Display products, prices, and quantities.
- Calculate subtotal and total number of items.
- Update the order summary dynamically.

### 3. Delivery Options
- Standard Delivery – $5.
- Express Delivery – $10.
- Optional preferred delivery date.
- Automatic delivery fee calculation.

### 4. Payment Methods
- Cash on Delivery.
- Credit/Debit Card payment simulation.
- Basic validation of card information.

### 5. Promo Codes
- `SAVE10` – 10% discount.
- `WELCOME5` – $5 discount.
- `FREESHIP` – Free delivery.

### 6. Order Processing
- Validate customer and payment information.
- Calculate the final order total.
- Generate a unique order number.
- Display an order confirmation.

### 7. Additional Features
- Printable order receipt.
- Order history saved using Local Storage.
- Option to clear order history.
- Start a new purchase after completing an order.
- Responsive design for different screen sizes.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start testing the checkout process.

No additional libraries, frameworks, or installations are required.

## Important Notes

- This is a front-end educational project.
- Product information is predefined inside the JavaScript file.
- No external API, backend, or database is required.
- Card payment is simulated; no real payment transactions are processed.
- Order history is stored locally in the browser using Local Storage.

## Project Goal

The main goal of this project is to practice JavaScript fundamentals through a practical E-Commerce checkout scenario, including DOM manipulation, event handling, form validation, arrays, functions, calculations, and browser Local Storage.
